# Ship Physics Balance Constants

Статус: очищено под текущий корабельный состав.

Старые физические расчеты по несуществующим кораблям удалены из активного
документа. Текущие корабли игрока:

| id | Название | Класс |
|---|---|---|
| `capital_patrol_frigate_r02` | Коршун | фрегат |
| `capital_artillery_cruiser_r02` | Барбет | крейсер |
| `capital_heavy_battleship_r02` | Вал | линкор |

Актуальные боевые скорости, ускорение, скольжение и loadout-параметры должны
браться из runtime-конфигов и проверок Big Test, а не из старых расчетов.
