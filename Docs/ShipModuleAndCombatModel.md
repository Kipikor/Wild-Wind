# Wild Wind: корабельные модули и боевая модель

Дата фиксации: 2026-06-27

Документ собирает принятые правила и черновые решения по корабельному
оборудованию, масштабу оружия, броне, урону и поведению модулей.

## Решено: продуктивность оборудования по размеру

Оборудование использует четыре визуально-геймплейных размера:

| Класс | Диаметр основания | Линейный множитель от S | Множитель продуктивности |
|---|---:|---:|---:|
| S | 4 м | 1.00x | 1x |
| M | 7 м | 1.75x | 3.5x |
| L | 10 м | 2.50x | 8x |
| XL | 16 м | 4.00x | 22x |

Физическая опора: продуктивность инженерного модуля растет примерно от
рабочей площади. Чем крупнее излучатель, пасть, катушка, линза, сифон,
сварочная голова или сканирующая апертура, тем больше энергии или материала
модуль может пропустить через себя.

Чистый квадрат размера дал бы S/M/L/XL как `1 / 3.06 / 6.25 / 16`.
Для игрового ощущения Wild Wind дает большим модулям небольшой бонус сверх
строгого квадрата: `1 / 3.5 / 8 / 22`.

Кубическую продуктивность по умолчанию не используем. Куб сделал бы XL-модуль
примерно `64x` сильнее S и слишком быстро обесценил бы малое оборудование.
Рост ближе к кубу остается для цены, массы, нагрузки на корабль, нагрева,
энергопотребления, обслуживания и требований к установке.

Общее правило баланса:

```text
продуктивность растет чуть быстрее площади;
масса, цена, энергодавление и сложность установки растут ближе к объему.
```

Смысл продуктивности по типам модулей:

| Модуль | Главная продуктивность | Вторичные ограничения |
|---|---|---|
| Магнитный луч | тонны притяжения в секунду | дальность, максимальная масса цели, стабильность удержания |
| Сальвагер | прогресс разборки в секунду | сложность цели, шанс достать ценные детали |
| Майнинг-луч | руда в секунду | твердость породы, потери при добыче, стабильность реза |
| Ремонтный луч | восстановление HP в секунду | расход материалов, максимальный размер обслуживаемого корабля |
| Разведывательный луч | прогресс сканирования в секунду | дальность, пробитие маскировки, глубина информации |
| Газовый сифон | газ в секунду | стойкость к опасной среде, дальность забора |
| Взломная турель | прогресс взлома в секунду | пробитие защиты, количество параллельных каналов |

Размер класса является основной геймплейной ручкой. Точная геометрия модели
может подсказывать вкус и роль, но баланс сначала смотрит на класс модуля,
а не пытается выводить каждое число из размеров меша.

## Решено: базовое бронепробитие оружия

Якорное правило для артиллерии:

```text
номинальное бронепробитие при средней дистанции и нормальном попадании равно калибру оружия
```

То есть в стандартных условиях:

| Калибр | Номинальное бронепробитие |
|---:|---:|
| 30 мм | 30 мм |
| 76 мм | 76 мм |
| 150 мм | 150 мм |
| 300 мм | 300 мм |
| 406 мм | 406 мм |
| 460 мм | 460 мм |

Это правило нужно как понятный язык для игрока и балансный якорь для дизайна:
если игрок видит калибр, он примерно понимает, какую броню это оружие должно
брать в честных средних условиях.

Рабочая формула для дальнейшей боевой модели:

```text
базовое_пробитие = калибр * модификатор_боеприпаса * модификатор_дистанции
эффективная_броня = толщина_брони / cos(угол_попадания)
```

Черновые ориентиры модификаторов:

| Условие | Эффект |
|---|---|
| Близкая дистанция | пробитие выше среднего |
| Средняя дистанция | 100% от калибра |
| Дальняя дистанция | пробитие ниже среднего |
| Хороший прямой угол | броня считается почти по номиналу |
| Острый угол | броня становится эффективнее, возможен рикошет |
| Бронебойный боеприпас | повышает пробитие |
| Фугасный/осколочный боеприпас | плохо пробивает броню, но лучше бьет внешние модули и площадь |

Итог попадания должен читаться ступенями:

- пробитие заметно выше эффективной брони: полный урон и хороший шанс повредить внутренний модуль;
- пробитие около эффективной брони: частичный урон, застревание, трещины, ограниченный шанс критического эффекта;
- пробитие ниже эффективной брони: непробитие, рикошет, скол или малый внешний урон.

## Решено: выбор кораблей на миссию

Игрок берет на миссию отряд из трех машин. Поэтому корабли балансируются не по
равной силе в вакууме, а по окупаемости, скорости, роли и риску внутри состава.

У корабля есть ограниченный ресурс вылетов: каждая машина может сходить в
вылет только 10 раз. Это является реальной ценой применения даже без отдельной
денежной оплаты за старт миссии. Линкор может быть намного сильнее фрегата, но
плохой выбор для мелкой задачи, если он сжигает один из своих ценных вылетов и
не окупает участие.

Базовая логика классов:

| Класс | Сильная сторона | Ограничитель | Нормальная роль |
|---|---|---|---|
| Фрегат | скорость, дешевизна применения, скрытность, точечная работа | слабее в прямом бою, меньше запас прочности | разведка, быстрые точки, добыча, взлом, добивание, торпедный налет |
| Крейсер | универсальность, средняя скорость, средняя живучесть | не самый дешевый и не самый мощный | основной рабочий корабль отряда |
| Линкор | огромная огневая мощь, броня, устойчивость | медленный, дорогой ресурсом вылетов, избыточный для мелких задач | тяжелый бой, зачистка, сопровождение опасной операции |

Фрегат не обязан честно перестреливать крупный корабль. Его сильная боевая
фантазия: скрытно подойти, выпустить торпеды по ключевой цели и уйти до того,
как тяжелые силы успеют его поймать. Это делает фрегат полезным даже в мире,
где линкор объективно мощнее почти во всех прямых числах.

Ключевой контракт:

```text
сила корабля оценивается через задачу, маршрут, время, риск и расход лимита вылетов,
а не только через победу в прямой дуэли.
```
