# Ship Concept Art Direction

This document tracks current ship visual references.

## Current Player Ships

| Ship | Source model |
|---|---|
| Korshun | `Docs/BlenderAssets/Ships/WW_Imperial_PatrolFrigate_R02_Korshun.blend` |
| Barbet | `Docs/BlenderAssets/Ships/WW_Imperial_ArtilleryCruiser_R02_Barbet.blend` |
| Val | `Docs/BlenderAssets/Ships/WW_Imperial_Battleship_Val.blend` |

The current player-facing roster is limited to these three ships. Old concept
references for starter/faction/branch ships are not active ship references.

## Visual Rule

- Use the authored Blender/FBX ship assets for player ships.
- Do not show procedural placeholder ships in port, dock, catalog, or player
  combat flow when an authored model exists.
- Temporary enemy square targets are a separate combat prototype and are not part
  of the player ship roster.
