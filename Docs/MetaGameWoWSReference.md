# Meta Game WoWS Reference

Статус: старый WoWS-черновик очищен.

Этот документ больше не является источником корабельного состава. Текущий
игроковый флот: Коршун, Барбет, Вал.

WoWS можно использовать только как UX-референс для порта, дока, камеры,
слотов, продажи и представления корабля. Нельзя переносить из старого черновика
дополнительные корабли, стартовые fallback-корпуса или длинные ветки.
