# Ship Crafting Component Plan

Статус: очищено под текущий состав кораблей.

Старые R1-R10 правила крафта удалены из активного канона. Сейчас крафтовые
таблицы могут ссылаться только на три корабля из текущего каталога:

- `capital_patrol_frigate_r02`;
- `capital_artillery_cruiser_r02`;
- `capital_heavy_battleship_r02`.

Новые ранги, лицензии, ветки и корпуса нужно проектировать заново, а не
восстанавливать из старых расчетов.
