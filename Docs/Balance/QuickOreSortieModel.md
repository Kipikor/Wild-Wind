# Quick ore sortie model

Статус: v0 для кнопочных быстрых вылетов.

Этот слой не описывает обычные ручные миссии. Быстрый вылет считается так, будто корабль сам нашел подходящую для себя рудную работу и вернулся со средним результатом.

## Входы

Для рудного быстрого вылета нужны два параметра корабля:

- `mining` - эффективность добычи руды;
- `cargo_capacity_tons` - физическая грузоподъемность в тоннах.

`mining = 0` означает, что корабль не может делать рудный быстрый вылет.

## Доступ к рудам и ресурс дробилки

Каждая руда имеет сложность `min_mining` и износ дробилки `crusher_wear_per_ton` в `ore_deposits.csv`.
`min_mining` больше не должен быть абсолютным запретом.
Он остается ориентиром сложности пласта и подсказкой для UI, но главный ограничитель - ресурс дробилки на один вылет.

Правило v1:

```text
load_factor = clamp(0.55 + mining * 0.0045, 0, 1)
crusher_budget = cargo_capacity_tons * load_factor * (0.75 + mining / 50)
ore_tons_possible = min(cargo_capacity_tons, crusher_budget / ore.crusher_wear_per_ton)
```

Смысл:

- мягкую руду можно перемолоть много;
- твердая руда быстро съедает дробилку;
- любой корабль теоретически может взять любую руду, но слабый корабль потратит весь ресурс дробилки на маленький объем дорогого пласта;
- большому рудному кораблю невыгодно гонять мощную дробилку по совсем бедной породе, потому что он теряет потенциальную ценность вылета;
- обычная ручная миссия позже сможет добавить отдельные требования опасности, биома и дальности.

Пример чтения `crusher_wear_per_ton`:

| Износ | Значение |
|---:|---|
| `0.55` | очень мягкая массовая руда, дробится легко |
| `1.00` | нормальная ранняя руда |
| `2.00` | твердая средняя руда, слабый корабль быстро устает |
| `5.00` | поздний тяжелый пласт, маленькая дробилка почти сразу выгорает |

## Заполнение трюма

Быстрый вылет не обязан заполнять весь трюм слабого добытчика.
Теперь это не только абстрактная "удачность", но и ресурс оборудования.

Формула v0:

```text
load_factor = clamp(0.55 + mining * 0.0045, 0, 1)
raw_ore_tons = cargo_capacity_tons * load_factor
```

Формула v1 с дробилкой:

```text
crusher_budget = cargo_capacity_tons * load_factor * (0.75 + mining / 50)
raw_ore_tons = min(cargo_capacity_tons, crusher_budget / average_crusher_wear)
```

Примеры:

| Mining | Заполнение трюма |
|---:|---:|
| 10 | 59.5% |
| 14 | 61.3% |
| 40 | 73.0% |
| 70 | 86.5% |
| 99 | 99.6% |

Это черновая ручка. Если ранние корабли окажутся слишком бедными, поднимаем базу `0.55`; если промышленные линкоры слишком быстро кормят экономику, снижаем коэффициент `0.0045`, множитель дробилки или веса дорогих руд.

## Качество пласта

Добытый объем распределяется между доступными рудами.

Для чернового расчета используем три сценария:

| Сценарий | Смысл |
|---|---|
| `bad` | корабль нашел простой бедный пласт из нижней части доступного списка |
| `normal` | средний вылет по `base_weight` доступных руд |
| `lucky` | удачный пласт по `lucky_weight`, чаще выбирает более ценную доступную руду |

На реальной кнопке можно показывать только итог, но для баланса эти три сценария дают понятный диапазон.

## Пример: Имперский `Возчик` R2

Корабль: `capital_cargo_frigate_r02`.

Параметры:

```text
mining = 14
cargo_capacity_tons = 50
load_factor = 0.613
raw_ore_tons = 30.6 т
```

Доступные руды:

| Руда | min_mining | Что дает |
|---|---:|---|
| Угольная гарь | 4 | уголь, немного железа и кварца |
| Ржавик | 8 | железо, кварц, кальцит |
| Белокварц | 10 | кварц, кальцит, немного магния и гемм |
| Соленый мел | 12 | кальцит, сильвин, кварц, немного гемм |
| Медная пыль | 14 | медь, кварц, немного железа |

Недоступно начиная с `Плотный ржавик` (`min_mining = 18`) и выше.

Угольная гарь 16.9 т
