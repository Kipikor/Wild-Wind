# Quick ore sortie model

Статус: старый корабельный пример удален.

Этот документ больше не содержит примеров с несуществующими кораблями. Для
быстрых вылетов текущие корабли игрока берутся только из
`Assets/Data/Config/Ship_catalog.csv`:

- Коршун;
- Барбет;
- Вал.

Любой новый пример добычи должен явно указывать один из этих кораблей или быть
добавлен только после появления нового реального корпуса в каталоге.
