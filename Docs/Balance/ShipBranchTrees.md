# Wild Wind: текущий реестр кораблей игрока

Статус: актуально для текущей реализации.

Старые ветки R1-R10 удалены из канона. В игре сейчас есть только три корабля
игрока:

| id | Название | Класс | Визуальная модель |
|---|---|---|---|
| `capital_patrol_frigate_r02` | Коршун | фрегат | `WW_Imperial_PatrolFrigate_R02_Korshun` |
| `capital_artillery_cruiser_r02` | Барбет | крейсер | `WW_Imperial_ArtilleryCruiser_R02_Barbet` |
| `capital_heavy_battleship_r02` | Вал | линкор | `WW_Imperial_Battleship_Val` |

Других кораблей игрока сейчас нет. Старые стартовые корабли, фракционные ветки,
R3-R10 лестницы и черновые корпуса не должны использоваться как источник данных,
баланса, UI или визуалов.

Временные вражеские квадратные цели в core combat не относятся к этому реестру:
это отдельный боевой прототип врагов.
