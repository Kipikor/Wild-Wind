# Барбет: баланс компонентов v0.2

Дата фиксации: 2026-06-30

Статус: рабочая балансная спецификация. Здесь зафиксированы принятые сейчас цифры для имперского тяжелого артиллерийского крейсера `Барбет` до подключения в рантайм-конфиги.

## База корабля

`Барбет` - тяжелый артиллерийский крейсер длиной 150 м. Это в первую очередь боевой корабль: тяжелый главный калибр, плотная ПМК, сильное присутствие в прямом бою, мало утилитарности.

## Правила стрельбы

Читаемое балансное поле для точности: `dispersion_m_per_km`.

Перевод в текущую рантайм-логику:

```text
dispersionAtMaxRangeMeters = dispersion_m_per_km * range_m / 1000
```

Пример: 30 м/км на 4000 м дает около 120 м разброса на этой дистанции. Это делает 60-метровый фрегат сложной, но не невозможной целью для неточной крейсерской фугасной поливалки.

Бронебойный снаряд должен наносить примерно x1.5 урона относительно фугаса похожей массы, потому что ББ может не пробить или срикошетить, зато при пробитии взрывается внутри.

Фугасы имеют радиус взрыва. ББ радиуса взрыва не имеют.

Новый общий источник радиуса фугаса - масса взрывчатки `explosive_kg`.
Рабочая опора баланса: `50 кг` TNT-equivalent дают `20 м` боевого фугасного радиуса.
Формула: `radius_m = 20 * sqrt(explosive_kg / 50)`.
The 50 kg / 20 m / 0.5 exponent anchor lives in `Assets/Data/Config/Core_tactical_balance.csv` and is intended to be balance-configurable.
Это не чистая физика ударной волны, а игровой радиус практического поражения:
воздушный удар, осколки, корпус снаряда, огонь и повреждение внешних систем
считаются вместе. `splash_radius_m` в CSV остается читаемым fallback, но новые
взрывные строки должны в первую очередь задавать `explosive_kg`.

Для фугасного непробития используем уже принятое квадратное падение:

```text
damage_ratio = (he_penetration / effective_armor)^2
```

Магнитные лучи не ограничиваются коротким фиксированным кулдауном как главным лимитом. Их фактический цикл:

```text
cycle_time = distance_to_target / pull_speed + load_or_cut_time
```

Сборочный магнит должен ощущаться как быстрый инструмент "схватил и втянул". Сальважный луч должен ощущаться ценнее и тяжелее: медленнее, короче и заметно дороже по заряду батареи.
