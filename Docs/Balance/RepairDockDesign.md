# Repair Dock Design

Repair Dock is a port source of persistent damaged ship finds. Each slot contains one random damaged ship; the rule is no reroll. The player must either repair it, then claim or sell it, or leave it waiting.

The dock scales from building level and mastery. Its target rank grows nonlinearly: mastery around 10 can see R5, mastery around 70 can rarely see R10. The average roll sits one to three ranks below the current target, and R10 stays rare even at maximum service.

Repair is cheaper than full crafting and uses lower-stage resources. A ship that would be crafted from blocks can be restored with details, prepared materials, raw processed resources and precise automaton parts instead of a full block recipe.

After all work steps are completed, the repaired ship has two outcomes. The player can claim it into an empty normal port slot with full sorties, or sell it immediately for Freight. Sale is discounted and should not beat normal progression; the main value is a random, cheaper fleet-breadth source.
