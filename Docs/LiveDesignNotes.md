# Live Design Notes

Статус: старые корабельные заметки очищены.

Актуальное правило для кораблей игрока простое: в проекте сейчас есть только
Коршун, Барбет и Вал. Старые заметки про стартовые корабли, fallback-корабли и
длинные ветки больше не являются источником правды.

Новые корабельные решения нужно фиксировать в отдельных актуальных документах и
сразу проводить через модель, FBX, конфиг и Big Test.
