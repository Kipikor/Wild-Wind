# Черновой список ресурсов, типов и веса

Статус: временный дизайн-док, не конфиг. Нужен, чтобы зафиксировать тип сущности, вес одной игровой единицы и короткую роль до переноса в CSV.

## Условности

- Для твердых и сыпучих материалов `1 ед.` обычно равна `1 кг`.
- Для жидкостей `1 ед.` равна `1 л`; вес указан в кг за литр.
- Для газов `1 ед.` равна `1 л` баллонного газа; вес намеренно игровой, не физический.
- Для руд `1 ед.` равна `1 кг`; состав руды удобно считать на `1000 ед. = 1 тонна`.
- Газовые облака сами не возятся как груз: возится их конденсат, который потом перегоняется в газы.
- Рецепты и знания предтеч не включены как материальные ресурсы: это отдельный слой прогресса.
